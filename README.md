# 29N a ciegas

Compara las propuestas principales de los partidos para las elecciones generales del 29 de noviembre de 2026 **sin ver qué partido las propone**. Elige la que más te convence en cada tema (o ninguna) y al final descubre con quién coincides.

- Next.js (export estático) desplegado en GitHub Pages.
- Los datos están en `data/programas.ts`, con fuentes y estado de cada programa.
- No es una recomendación de voto.

```bash
npm install
npm run dev
```
